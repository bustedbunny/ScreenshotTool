# ScreenshotTool 1.2.0

## Downloads

- **Installer:** `ScreenshotTool-1.2.0-windows-x64-setup.exe` installs for your account under `%LOCALAPPDATA%\Programs\ScreenshotTool`, with a Start Menu shortcut and an optional desktop shortcut. No administrator rights are required.
- **Portable:** extract `ScreenshotTool-1.2.0-windows-x64.zip` to a writable folder and run `ScreenshotTool.exe`.
- **Standalone executable:** `ScreenshotTool.exe` remains available for portable use and in-app updates.

Windows 11 build 22000 or later on native x64 hardware is required. The app and installer are unsigned.

## Changes since 1.1.0

- Added the per-user installer, an application icon, repair and upgrade support, and Installed Apps version refresh after in-app updates.
- Added English, Russian, Simplified Chinese, Japanese, German, and Spanish UI translations, with automatic Windows display-language selection.
- Added **Apply** in Settings to save changes and switch language while keeping the dialog open.
- Dragging blank canvas outside the crop now replaces the selection with any tool active, while preserving annotations and the selected tool.
- Added keyboard shortcuts to toolbar captions and refined the active-button appearance.

Close ScreenshotTool before installing or uninstalling. Setup preserves an existing enabled sign-in preference and points it at the installed app; a fresh installation leaves it disabled. Uninstall preserves settings and screenshots and removes the sign-in entry only if it still points at that installation. In-app updates continue replacing the executable at its current path.
